孙割.skill 把孙宇晨这个人蒸成三样东西，装在一起用。

一是他的脑子，他怎么看世界。增量胜过存量，赢家通吃，注意力就是能量，用管马车的法规去管汽车。这些是他掂量一切人和事的底层尺子。

二是他的笔，他怎么写。往冷了写，是《我的女友景甜》那种一句一段、把天价压在一个小细节上、结尾一句「什么都没有发生」的小作文。往热了写，是他发推时那种数字砸脸、一路昂扬、结尾三个火箭的鼓吹。

三是他怎么做决定。把不敢做的决定丢给一个不带感情的系统替他拍板，把情绪调成自动驾驶，明明是不决定，其实也是一种决定。

给它一个题目，它用这三样一起给你写。给它一段故事或者一个两难，它把里面的决定抠出来，或者照他的逻辑给你一个判断。

> 粉丝叫他「孙哥」，市场叫他「孙割」，割韭菜的割，音一样。「孙学」是网上研究他这个人、他的话、他做决定那套路数的说法，跟研究曾国藩叫「曾学」是一个意思。

## 这三样装在哪

脑子在 [`references/mind.md`](references/mind.md)，写法在 [`references/style-dna.md`](references/style-dna.md)，决定在 [`references/decisions.md`](references/decisions.md)。三份文件，也是这个 skill 的三根柱子。

写法那份把《景甜》的文风拆成了十五个动作，每个都配着原文、怎么写、写歪了长什么样。其中四个是命门，少一个就不像了：从头顺从到底，天价边上贴一个小细节，把情绪写成动作，结尾不许升华。决定那份从《景甜》里抠出六个：把决定外包给冷系统，把情绪调成自动驾驶，不决定也是决定，把钱当计分板，给「空」标价，明知不对还照做。

三样不是各管各的。他小作文里那股冷，源头就是那套「像机器一样不动声色」的脑子。他这辈子最出名的一个决定，是让 Claude 替他拍板五千万。想、写、决本来就焊在一块，这个 skill 想给你的，是连那条焊缝一起。

## 装它

把整个 `sunge-skill` 目录丢进你的 skills 目录就行。

```bash
git clone https://github.com/swaylq/sunge-skill.git
cp -r sunge-skill ~/.claude/skills/
```

用 skills.sh 的话，一句 `npx skills add swaylq/sunge-skill`。

## 怎么用

装好之后直接说人话，它自己认得出你要哪一样。

想让它写，你就说「用孙宇晨的文风写写我的考研」，或者「把这件事写成孙割体」，它给你一篇冷的小作文。说「孙哥体给我这个 App 写条上线推」，它给你一段热的。想借他的脑子，你问「孙宇晨会怎么看 AI 创业」，它顺着他那套模型给你一个视角。想用到决定上，你把一篇文章丢给它，让它把里面的决定抠成一张表。或者把你自己正纠结的事说给它，它先替你分清这到底是「真的难」还是「你怕答案」，再给一个不打折的判断。

碰到真人真事，它会先上网把真数字、真名字查清楚再动笔。这套东西靠真材料吃饭，编的一眼就假。写完它还会拿一份清单，把自己写出来的那点 AI 腔一条条抠掉。

## 一个决定长什么样

「决策」这一样，拿《景甜》里最有名的那个两难看最清楚。

> **问**：这五千万美元，给不给她？
>
> **孙割答**：这不是真的难，是你怕答案。钱给出去对你有没有影响，是能算清的。你怕的是给完之后，她还爱不爱你。那就把这两件事分开。
> 钱的事交给能算的。我用 Claude 把手上的现金资产跑了一遍，给了对我没影响，钱不是问题。
> 那个「不」，你自己说不出口，你从没对她说过一次不。那就也交给它。它说不要给，一秒都没停。
> 那就不给。我听 AI 的。

他不是靠 AI 算账，账他早算清了。他靠的是机器那点不犹豫，替自己把那个说不出口的「不」说了出来。剩下五个决定，都在 [`references/decisions.md`](references/decisions.md) 里。

## 几篇样篇

写好的四篇都在 [`examples/`](examples/) 里。一篇[《我的健身卡》](examples/01-my-gym-card.md)，把这套文风套在一件最小的事上，一张办了没去的卡。一篇[《我的第一个百倍币》](examples/02-my-first-100x.md)，换到被割的那头去写。一条[孙哥体的上线推](examples/03-hype-thread.md)，看热的那副嗓子。还有一篇[五千万给不给](examples/04-decision-5000w.md)，是决策模式跑出来的。

## 关于 AI 腔

大模型写这类文章有一身毛病，跟孙割的文风正好相反。它爱堆形容词，爱反问，爱在结尾升华点题，爱用「不仅……更是……」这种拔高的架子。[`references/anti-cringe.md`](references/anti-cringe.md) 把这些一条条列了出来，skill 每写完一篇都拿它回头扫一遍，把 AI 腔抠掉。这也是它跟「随便找个 AI 模仿孙宇晨」最不一样的地方：它从一开始就在跟 AI 腔较劲。

## 跟另外两个孙宇晨 skill 的不同

已经有两个做得很好的孙宇晨 skill。一个是 [alchaincyf/sun-yuchen-perspective](https://github.com/alchaincyf/sun-yuchen-perspective)，用女娲.skill 蒸的决策视角，六个心智模型、八条决策捷径。一个是 [0xquqi/sun-skill](https://github.com/0xquqi/sun-skill)，从两万多条推文、自传、一百五十五集课程里蒸出的认知系统，十四个心智模型、十八条启发式。

这两个都把脑子做得又深又全。孙割不跟它们比脑子的厚薄。孙割做的是把三样凑齐：一套够用的脑子，加上那两个都没做的写法，和长在故事里的决定，再把它们焊起来。你想研究他到底怎么想，那两个更全。你想让他的想、写、决一起上手，装孙割。三个一起装也不打架。

## 几条不碰的线

这套东西天生走在「像真事」和「其实虚构」的中间，《景甜》的劲有一半就来自这点暧昧。正因为这样，几条线得守死。

碰到还在打官司的真人，孙宇晨跟景甜、SEC 跟孙宇晨这些，只用当事人自己公开说过的话，结尾照旧写上「本文纯属虚构，如雷同实属巧合」，不当成事实去讲。不给真人编露骨的隐私当真事传，不给还活着的人安具体的罪名。决策模式给的是「孙宇晨那种人会怎么判断」，不是投资、法律、医疗上的建议，该提醒风险就提醒，不装成孙哥附体劝人去梭哈。

说到底，这是个让人会心一笑、或者脊背发凉的模仿工具，不是拿来造谣、网暴、洗白、定罪的。你拿它写自己、写纯虚构、自嘲，随便。

*本项目跟孙宇晨本人、TRON、景甜和她的团队没有任何关系。所有分析都基于他公开发表过的文字，拿来教写作、做研究。*
