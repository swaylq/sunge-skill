孙割.skill 把孙宇晨这个人蒸成三样东西，装在一起用：

- **🧠 大脑** —— 他怎么看世界。增量 > 存量、赢家通吃、注意力就是能量、马车法律管汽车……一套心智模型和世界观。
- **✍️ 写作风格** —— 他怎么写。从《我的女友景甜》那种冷到脊背发凉的小作文，到发推时数据轰炸、🚀 收尾的昂扬热推。
- **🎯 决策能力** —— 他怎么做决定。把不敢做的决定外包给冷系统、把情绪调成自动驾驶、不决定也是一种决定……

给它一个题目或一个处境，它用他的脑子、他的笔、他的决策逻辑，一起给你产出。

> **两个名字**：粉丝叫他「孙哥」，市场叫他「孙割」（割韭菜的割），同音。「孙学」是网友对「研究孙宇晨其人、其言、其决策法」的戏称，跟「曾学」（研究曾国藩）一个路子。

## 蒸了哪三样

| | 是什么 | 装在哪 |
|---|---|---|
| **🧠 大脑** | 心智模型 + 价值排序 + 人设的裂缝（写他要立体，矛盾不省） | [`references/mind.md`](references/mind.md) |
| **✍️ 写作风格** | 把《景甜》那套文风拆成 **15 个可复用写法**，每条带原文 + 怎么写 + 写歪长啥样；**4 条是命门**：顺从到底、天价配细节、情绪写成动作、结尾不升华 | [`references/style-dna.md`](references/style-dna.md) |
| **🎯 决策能力** | 从《景甜》抠出的 **6 个关键决策**（外包给冷系统 / 情绪自动驾驶 / 不决定也是决定 / 钱当计分板 / 给「空」定价 / 明知不对仍照做）+ 决策底册 | [`references/decisions.md`](references/decisions.md) |

三样不是各管各的：他小作文的冷，源头就是「像 AI 一样减少情绪波动」那套大脑；他最出名的一次决策，是让 Claude 替他拍板。**想、写、决是焊在一起的**，这个 skill 的重点就是把这条焊缝也给你。

## 装它

**Claude Code**：把整个 `sunge-skill/` 目录放进你的 skills 目录即可。

```bash
git clone https://github.com/swaylq/sunge-skill.git
cp -r sunge-skill ~/.claude/skills/
```

## 怎么用

装好后直接说人话，它会自己分用法：

| 你想要 | 它给你 |
|---|---|
| 「用孙宇晨的文风写写我的考研」「把 X 写成孙割体」 | 一篇冷小作文（主打） |
| 「孙哥体给我这个 App 写条上线推」 | 一段昂扬热推 |
| 「孙宇晨会怎么看 AI 创业」 | 用他的大脑给一段视角 |
| 「帮我分析这篇里的关键决策」 | 把故事里藏的决策抠成一张表 |
| 「用孙宇晨的逻辑，我这笔钱该不该投」 | 先分清你「真的难」还是「怕答案」，再给个不含糊的判断 |

涉及真人真事，它会先联网查真数字、真专名，再动笔——**这套东西靠真材料吃饭**，编的一眼假。写完还会拿一份「去 AI 味」的排雷清单自查（见下）。

## 决策案例

「决策能力」这一样长什么样，看这条——取自《景甜》里最出名的两难：

> **问**：这五千万美元，给不给她？
>
> **孙割答**：给了对我有没有影响，我算过。用 Claude Code 把所有现金资产跑了一遍，没有任何影响。我又核了一遍，还是没有。所以这不是钱的事。
> 我从来没有拒绝过她。不是慷慨，是害怕，害怕下一秒的答案。
> 我把问题打进 Claude。我问，要不要给。它说，不要把这五千万给她。我问，她是不是不再爱我了。它说，对于爱情，我不关心，也不理解，但是你不能把这五千万给她。
> 它说得很快，一个字没停。让我毛骨悚然的不是它算得对，是它一点犹豫都没有。它不为难。
> 那个「不」，我没有说出口。我让它替我说了。
> **我听 AI 的。**

他不是靠 Claude 算账，账早算清了。他要的是机器那点不犹豫，替自己说出那个自己说不出口的「不」。完整六条决策在 [`references/decisions.md`](references/decisions.md)。

### 关于「去 AI 味」

大模型写这类文有一堆坏习惯，跟孙割的文风**正好相反**：爱堆形容词、爱反问、爱「然而其实」、爱在结尾升华点题。[`references/anti-cringe.md`](references/anti-cringe.md) 专门收录这些翻车现场，skill 每写完一篇都拿它自查一遍，逐条掐掉 AI 味。这也是它跟「随便让个 AI 模仿孙宇晨」最大的差别——**默认就在跟 AI 味对着干。**

## 跟另外两个孙宇晨 skill 的区别

已经有两个很好的孙宇晨 skill：

- [alchaincyf/sun-yuchen-perspective](https://github.com/alchaincyf/sun-yuchen-perspective) —— 女娲.skill 蒸的决策视角，6 个心智模型、8 条决策捷径。
- [0xquqi/sun-skill](https://github.com/0xquqi/sun-skill) —— 21,829 条推文 + 自传 + 155 集课程蒸的认知操作系统，14 个心智模型、18 条启发式。

这两个都把**大脑**做得很深很全。孙割不跟它们比大脑的厚度——孙割的定位是**三样合一**：一套够用的大脑，加上前两个都没覆盖的**写作风格**和**长在故事里的决策**，再把三者焊起来。你要研究他怎么想，那两个更全；你要他的想、写、决一起上，装孙割。三个都装也不冲突。

## 红线

这套东西天生游走在「疑似真事」和「自署虚构」之间——《景甜》的杀伤力有一半来自这种暧昧。正因为危险，skill 守死几条：

- 涉及真人**未决纠纷**（孙宇晨 vs 景甜、SEC vs 孙宇晨），用当事人公开口径，结尾带「本文纯属虚构，如雷同实属巧合」，不当事实断言。
- 不给真人捏造露骨的性、生育、医疗隐私当真事传播；写在世真人不发明具体罪名。
- 决策模式给的是「孙宇晨那种人会怎么判断」的视角，**不是投资/法律/医疗建议**；该提示风险就提示，不以「孙哥附体」的口吻怂恿梭哈。
- 这是让人会心一笑或脊背发凉的**模仿工具**，不是造谣、网暴、洗白、定罪的工具。生成物默认带免责声明；你拿它写自己、写纯虚构、自嘲，随意。

*本项目与孙宇晨本人、TRON、景甜及其团队无任何关联。所有分析基于其已公开发表的文字，用于写作教学与研究。*
