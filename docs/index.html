2026 年 8 月，孙宇晨发了一篇《我的女友景甜》，一夜传疯。句子冷得像判决书，写的却是五千万美元、专机、和一个让男人改口叫「妈妈」的女人。每段都短，每段都往下压，最后一句是「什么都没有发生」。

好多人读完想学，学不像。它看着简单，其实每句背后都是一个准动作：把天价贴着一个小细节写，把心碎写成「心跳很稳」，让「我」从头顺从到尾，结尾绝不升华。孙割.skill 把这套写法拆成了十五个可复用的动作。给它一个题目，一个人、一件事、一张办了没去的健身卡，它照同一套机关还你一篇。

蒸了哪三样

🧠 大脑 · 他怎么看世界

增量胜过存量、赢家通吃、注意力就是能量、用管马车的法规管汽车。一套心智模型和世界观。

✍️ 写作风格 · 他怎么写

往冷了写，是《我的女友景甜》那种一句一段的小作文；往热了写，是他发推那种数字砸脸、火箭收尾的鼓吹。

🎯 决策能力 · 他怎么做决定

把不敢做的决定丢给一个不带感情的系统替他拍板，把情绪调成自动驾驶，不决定其实也是一种决定。

一个决定长什么样

取自《景甜》里最有名的两难，孙宇晨本人的口吻：

这五千万美元，给不给她？

给了对我有没有影响，我算过。用 Claude Code 把所有现金资产跑了一遍，没有任何影响。所以这不是钱的事。
我从来没有拒绝过她。不是慷慨，是害怕，害怕下一秒的答案。
我把问题打进 Claude。我问要不要给，它说不要。我问她是不是不再爱我了，它说，对于爱情，我不关心，也不理解，但是你不能把这五千万给她。
让我毛骨悚然的不是它算得对，是它一点犹豫都没有。
那个「不」，我没说。我让它替我说了。我听 AI 的。

怎么装

把整个 sunge-skill 目录丢进你的 skills 目录就行。

git clone https://github.com/swaylq/sunge-skill.git
cp -r sunge-skill ~/.claude/skills/

用 skills.sh 的话，一句 npx skills add swaylq/sunge-skill。装好之后直接说人话：「用孙宇晨的文风写写我的考研」「把这件事写成孙割体」「用孙宇晨的逻辑帮我拆这个两难」。
