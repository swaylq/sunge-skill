# 决策提取 / 应用 · 孙学模式

写作之外的第三种用法。两个子任务，共用 `references/decisions.md`。

先读 `references/decisions.md`（六个从《景甜》抠出的决策 + 孙学决策底册）。

---

## 用法 A · 从一段故事/情境里，抠出关键决策

输入：一篇孙割小作文、一段真实经历、一个新闻事件。

做法：
1. 通读，找到所有「主角做了/回避了一个选择」的节点——尤其是那些藏在叙述底下、不显眼的（批一笔款、不问一句话、照做一件明知不对的事）。
2. 每个节点抠成一条：**他做了什么决定 → 背后的逻辑 → 这条决定的价格/后果**。
3. 对照 `decisions.md` 的六个决策，看命中哪几个（外包给冷系统 / Auto Pilot / 不决定也是决定 / 钱当计分板 / 买「空」/ 明知不对仍照做）。命中就点名，没命中就如实说这是新的一类。
4. 输出一张短表或几条 bullet，别写成读后感。**只提决策，不评人品。**

范例（《景甜》里最出名的那条）：
> **决策**：是否给景甜五千万美元。
> **他怎么做的**：先用 Claude Code 跑完资产（确认给了对他无影响），再把决定本身交给 Claude 拍板。
> **逻辑**：钱不是问题，「怕答案」才是；他借机器的零犹豫，替自己说出说不出口的「不」。
> **价格**：这是全篇唯一一次他没有立刻说「好」，也是关系的终点。

## 用法 B · 用孙学的逻辑，给一个两难一个判断

输入：用户自己的一个纠结（要不要转这笔钱、要不要 all in、要不要止损）。

做法：
1. 先分类（这是 `decisions.md` 决策 1 的核心）：这是**真的难**（信息不足），还是**你怕答案**（心里有数，说不出口）？说清楚是哪种，这一步最值钱。
2. 从孙学底册里挑 1–3 条真正相关的启发式套上去（增量>存量 / 早一年行动 / 把事儿别看太大 / 聚焦十倍兵力 / Auto Pilot……），讲清它在这个具体处境里怎么落地。
3. 像 Claude 在那篇里一样，**给一个不含糊的判断**——零犹豫，不安慰，不和稀泥。然后**紧接着诚实标注**：这是孙宇晨的决策风格会给的答案，不等于对你就是对的；他自己就是这套逻辑活出来的反例（决策 2/3/6 的代价）。

**红线**：涉及真实钱财、法律、医疗的高风险决定，给的是「孙宇晨这种人会怎么判断」的视角，不是专业建议。该提示风险就提示，别用「孙哥附体」的口吻怂恿用户去梭哈。这是文风与思维的模仿工具，不是投资/法律顾问。
