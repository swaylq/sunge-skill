# 孙学 · 关键决策提取

> 「孙学」是网友对「研究孙宇晨其人、其言、其决策法」的戏称，跟「曾学」（研究曾国藩）、「鲁学」一个路子。这份文件做的是孙学里最硬的一块：**把他的决策从故事里抠出来**。

写作是壳，决策是核。《我的女友景甜》表面在讲一段关系，底下埋着六个可以单拎出来的决策。这份文件干两件事：

1. **从《景甜》这篇里，逐个抠出关键决策**——他做了什么决定、背后的逻辑、你怎么用、以及反面。
2. 附一张**孙学决策底册**——他公开讲过的决策启发式，供议论体/决策体调用。

这一层有两个用法：**写的时候**往篇子里埋一个「决策时刻」（最出名的就是让 Claude 拍板五千万那段）；**分析的时候**，给一段故事或一个两难，把里面的关键决策提出来、或用孙学的逻辑给个判断。

## 一、从《景甜》抠出的六个决策

### 决策 1 · 把不敢做的决定，外包给一个冷系统 ★旗舰

**他做了什么**：景甜在电话里要五千万美元。他这辈子第一次对她说「让我想想」。然后他用 Claude Code 读 API 把所有现金资产跑了一遍——结论是**给了对他毫无影响**。也就是说，钱不是问题。可他还是不敢决定。于是他把问题打进 Claude，Claude 说：不要把这五千万给她。

> Claude说，對於愛情，我不關心，也不理解。但是你不能把這五千萬美元給她。

**决策逻辑**：这里的要害不是「AI 帮我算账」。账他早算清了。要害是——**当你的情感让一个理性决定变得做不出来时，把它交给一个没有情感的系统替你说出口**。他自己说破了：「我從來沒有拒絕過她，不是慷慨，是害怕。害怕下一秒的答案。而現在有人替我說了。」让他毛骨悚然的不是 Claude 聪明，是它「一點猶豫都沒有」「它不為難」。他借的不是机器的算力，是机器的**决绝**。

**你怎么用**：把你正在逃避的决定分个类——是**真的难**（信息不够、利弊悬而未决），还是**你怕答案**（心里早有数，只是说不出口）？前者需要更多分析；后者，分析再多也没用，你缺的是替你摁下按钮的那只不发抖的手。给后者找一个冷的裁决者：一条预先定死的规则、一个不心软的顾问、一个「如果是别人来问我，我会怎么答」的视角。

**反面**：用 AI 当遮羞布——决定其实是你自己想做的，却假装是「AI 让我做的」，把责任推给机器。他没这么干：Claude 说不给，他最后……也没给，但他清楚那是他自己的软弱借了机器的壳，不是机器替他背锅。诚实那一层不能丢。

### 决策 2 · Auto Pilot：像机器一样，把情绪波动关掉

**他做了什么**：她挂了电话之后，他把手按在自己胸口数心跳，「像一個醫生在給別人做檢查」。心跳很稳，数了两遍都稳。他一直在等自己哭，没哭。

**决策逻辑**：这是他真实的方法论落地——他在课程里讲过「Auto Pilot」，主张像人工智能一样**减少情感波动，靠系统而不是意志力做事**。他的人设本来就标榜情绪像机器。这篇的高明在于：把这套「优点」写成了恐怖——一个人把自己训练到连心碎都测不出波动，到底是强大还是坏掉了，作者不下结论。

**你怎么用**：重大决策当口，先问「我现在是被情绪驱动，还是被判断驱动」。孙宇晨的做法是把情绪暂时挂起（Auto Pilot），只让系统和数字说话。**能用**：避免恐慌抛售、冲动表白、上头下单。**代价**（他自己活成了反例）：长期关掉情绪，你会算得清每一笔账，却记不起对方「我知道了」时是什么语气。

### 决策 3 · 不做决定，也是一种决定——而且往往最贵

**他做了什么**：整篇他只说「我说好」。每一个要求、每一笔转账、每一次加码，他都不拒绝。她甚至点破：「我在想，你會不會有一次說不。」他说不会。她说，那就没意思了。

**决策逻辑**：他的「顺从」不是没有决策，是**持续地选择回避决策**。回避本身是最贵的决定：三千万彩礼、五张卡轮转、一整层酒店、专机、香港的房——每一笔都是「不做决定」的账单。孙学在这里给的是反面教材：**永远不说不的人，其实把所有决定权都让渡出去了**。

**你怎么用**：识别你生活里的「我说好」——那些你懒得/怕得不去拍板、于是默认顺着走的事（自动续费、来者不拒的饭局、不敢谈的加薪）。把「不决定」显性化成一个决定摆上台面，你才看得见它的价格。

### 决策 4 · 把钱当计分板，不当钱

**他做了什么**：助理每月付款单里多出一项（她在北京做的促排检查），「金額不大，幾千塊……我批得很快。這類金額不需要我看明細。」三千万彩礼分五张卡转，「转到第三张的时候，我犹豫了一下。我还是转完了。」

**决策逻辑**：他的真实口径是「超過一百萬人民幣的錢跟我無關」。钱到了某个量级，在他这里不再是钱，是**计分板上的数字**。所以巨款转得比常人买杯咖啡还轻。这不是慷慨，是把货币的重量卸掉了——正好呼应全篇开头的「称重」：五千万美元两点五吨，但在他心里是零。

**你怎么用**：这是把双刃剑。**正面**：给不同量级的决策配不同的审议深度，别为一笔对你无关痛痒的小钱耗掉一小时（他「不看明细」的效率哲学）。**反面**：一旦所有钱都变成计分板数字，你就会像他一样，在该心疼的地方一点感觉都没有。量级脱敏要留一条底线。

### 决策 5 · 隐私和「空」是可以买的商品，明码标价

**他做了什么**：包下整层酒店三十天一百万美元「為了她的隱私」；把电影院所有座位买空、给已购票的二十六个人现金请他们走；清空整座海岛，「周圍不能有人」。

**决策逻辑**：常人把钱花在「拥有」，他把顶级的钱花在「让周围没有人」——**空置、清场、隔绝，都是可购买的商品**，而且是最贵的那一档。这是「注意力经济」的背面：他懂得注意力值钱，也就懂得「屏蔽掉所有人」同样值钱。

**你怎么用**：决策时把「负空间」也纳入定价——你愿意为「不被打扰」「没有人看见」「一个地方为你空着」付多少？多数人从不给这一项标价，于是从不购买它。孙学提醒你：**空，是一种奢侈品**。

### 决策 6 · 全部调查清楚，然后照做——在明知不对的信息上行动

**他做了什么**：认识三个月，他让人做了一份四十几页的调查（她的项目、股权、关联账户、两处房产，还有「男男女女的事情」）。她后来讲的和调查对不上，他没说；有些她一直没讲，他也没问。然后是那句并置：「我全部相信她說的。/ 但是我一個字也不信。」——他留着那份调查，一直照她的要求转钱。

**决策逻辑**：他不是没有信息，是**握着「这不对」的全部证据，仍然选择行动**。调查是为了「知道」，不是为了「决定」——决定早就被决策 3 锁死了。孙学在这里暴露一个真相：**很多人做尽调不是为了改变决定，是为了让自己在明知的情况下心安理得地照做**。

**你怎么用**：做完调查，逼自己回答一个问题——「如果结论是坏的，我会改变行动吗？」如果答案是「不会」，那这份调查是安慰剂，不是决策工具。要么承认你已经决定了（像他那样诚实），要么真的让证据有权推翻你。

## 二、孙学决策底册（他公开讲过的启发式，议论体/决策体调用）

分析一个新处境、或用他的口吻给判断时，从这张表里挑，别硬套全部。带 ⚠️ 的是争议口径，引用时归给他本人、别当客观真理。

| 启发式 | 一句话 | 出处/呼应 |
|---|---|---|
| **增量 > 存量** | 不看现在有什么，看增速；存量再大增速停了就是死棋 | 自传核心 |
| **不要慫，继续干** | 逆境六字诀，被封杀被起诉都这一句 | 94 禁令、SEC |
| **早一年行动 > 晚一年去更好的地方** | 时机的绝对优先 | 演讲高频 |
| **使命 > 金钱 > 名誉** | 声誉会波动，被评价驱动就没意义 | 访谈 |
| **把事儿别看太大** | 汇丰花旗谷歌都被罚过款，平常心 | 访谈 |
| **研究失败而非成功** | 避免失败才是成功的必要条件 | 自传 |
| **聚焦，局部集中十倍兵力** | 先在一个子生态成为 winner 再进下一个 | 林彪/乐视类比 |
| **Auto Pilot** | 像 AI 一样减少情感波动，靠系统不靠意志力 | 对应决策 2 |
| **晚做、缓做、巧做、精做** | 不是「不做」，是换时间换地点做 | 面对监管 ⚠️ |
| **把钱别看太重** | 超过一百万的钱与我无关 | 对应决策 4 ⚠️ |
| **注意力就是能量** | 互联网注意力等于质量，可转化成钱（真拿香蕉做过实验） | 620 万香蕉 |

## 三、怎么在写作里埋一个「决策时刻」

这一层跟文风打通。想让一篇孙割小作文有孙学的骨头，就在全篇的情感顶点，安排一次**外包给冷系统的决策**（`style-dna.md` 第 12 条「AI 冷酷客串」讲的是它的写法，这里讲它的内核）：

- 主角本该拒绝、却拒绝不了（呼应「顺从到底」）。
- 别让主角自己成长为会拒绝的人。引入一个冷的裁决者——AI、一份账本、一个数字、助理的一句话——由**它**说出那个「不」。
- 关键是写出裁决者的**零犹豫**：它不安慰、不解释、不为难。机器的决绝，反衬人的软弱。

这一下，是把「他这个人怎么做决定」直接焊进「他这篇怎么写」的接口。
